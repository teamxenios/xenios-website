# First hour: an execution target, not a checkout promise

The clock begins when the existing coordinator receives the explicit kickoff,
not when this document is generated. If source authority, a usable runner or
canonical legal/payment input is missing, identify that dependency immediately.
Do not wait an hour to reveal it.

| Window | Work | Required result |
|---|---|---|
| 0-10 min | Coordinator reconciles active owners and exact branches; selects one source scope and runner; policy/persistence owners read actual contracts. | One ownership map, one consolidated missing-decision packet, no duplicate sessions. |
| 10-25 min | Execute already-authorized HTTP regressions if a fresh valid reservation exists. In parallel, finalize canonical transaction/currentness and UI integration contracts within source scope. | Actual test receipts or explicit refusal; concrete design decisions, not a generic audit. |
| 25-45 min | Build the permitted coherent source slice: disabled mount/privacy/PWA after exact permission, or new persistence modules after scope/design approval. Add targeted tests with source. | Pushed exact reviewable source; no fake durable adapter. |
| 45-60 min | Existing reviewer checks the changed behavior; prepare/perform actual candidate preview if allowed; reconcile remaining dependencies. | Demonstrated current candidate and a factual milestone report. |

The table is a pacing proposal. It does not predict that unimplemented durable
persistence, managed qualification or payment integration can finish in those
windows. Source work and tests that exceed them continue in the same task.

At minute 60 report: what a customer can do; exact preview/deployment state;
what is actually persisted; who can read it; whether payments are absent/test/
verified live; source/evidence identifiers; and remaining blockers with owners.

Do not present localhost as a customer link or publish a disabled form as the
completed milestone. It is acceptable to have an excellent source checkpoint
without a production release. It is not acceptable to pretend that is buying.
