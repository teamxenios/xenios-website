A: request -> canonical durable record -> receipt/replay -> operator readback.
B: eligible quote -> real payment rail -> independent verification -> fulfillment.
C: complete qualified public/customer/partner/admin website.

The first-hour milestone is a demonstrated state and concrete source progress,
not guaranteed live buying. Keep the harness out of the release critical path.

execution contract. The common exact source/authority facts are in
STATE_ANCHORS.json and MOUNT_BASELINES.json. Refresh current Git before using.
