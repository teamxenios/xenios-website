### Precise proof limits (pre-existing deferred requirement, not a regression)

The timer is a browser-elapsed-time bound on a mounted descriptor. It does not prove exact server-relative expiry under arbitrary skew; a throttled background tab can let an already-decoded image stay displayed past server expiry, and a stale descriptor on remount is caught by `expiry <= now` or by the storage load failing (`onError` → fallback) rather than by server time. In every such case the pixels are still the approved bytes for that `mediaId`/hash, and storage remains the only access authority, so nothing here grants anything. The producer discloses this correctly and does not substitute a static `evaluatedAt` for timer time.
